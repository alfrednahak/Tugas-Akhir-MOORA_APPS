# Aturan Proyek: MooraFruits

## Gambaran proyek
- Aplikasi desktop Java Swing, dibuat di NetBeans, build dengan Maven.
- Package utama: V_From (kode ada di src).
- Library eksternal ada di folder lib (contoh: AbsoluteLayout-SNAPSHOT.jar).
- Metode SPK: MOORA. Objek: pemilihan buah layak jual.

## Aturan form (wajib)
- Setiap form baru harus berupa JFrame Form NetBeans, bukan JFrame biasa buatan tangan.
- File .form harus dipertahankan dan dibuat berpasangan dengan file .java.
- Jangan menghapus atau menulis ulang blok kode "Generated Code" milik NetBeans.

## Jangan diubah
- Sidebar kiri berwarna navy: jangan diubah warna, ukuran, urutan, atau tombolnya.
- Form Hasil MOORA dan CetakanHasilRanking: jangan ikut berubah. Menu Laporan adalah form terpisah (FormLaporan).

## Aturan perhitungan
- Bobot kriteria memakai angka desimal dan totalnya harus 1.0.
- Jangan mengubah rumus MOORA kecuali diminta secara eksplisit.
